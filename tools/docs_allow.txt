# tools/check_docs.py reads this. Two rules, both earned on the first run:
#
# 1. An entry is page-relative-path:name, not a bare name. RADIO_PRE_SYNC_US is
#    a correct historical quotation on radio/driver.md and was a stale claim in
#    live arithmetic on radio/timebase.md on the same day. A name-keyed list
#    cannot say that, and one line would have silenced the wrong occurrence.
# 2. The reason after # is required, not conventional. An exemption without one
#    is reported as a defect of this file, because a list that absorbs a real
#    stale name is worse than no list.
#
# A bare name with no colon still exempts everywhere, for algebra and for terms
# that are not identifiers anywhere.
